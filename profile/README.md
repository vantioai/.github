# Vantio

Vantio AI is a Pittsburgh-based cybersecurity startup founded in 2026. It builds infrastructure-level security and governance for enterprise autonomous AI agents and large language models — operating-system and host-level controls, not a software-only app layer.

Optics helps you see. Gate applies the rules you set. Phantom Engine protects the machines you own — enforce and control together, one purchase. Phantom Engine Enterprise adds governance when you need proof and process on top.

Blind by design. Not a proxy. We do not read private conversations.

| Product | Job | Workflow | List |
|---------|-----|----------|------|
| [**Vantio Optics**](https://github.com/vantioai/vantio-open-core) | Observe | Sight Loop | Free |
| [**Vantio Gate**](https://github.com/vantioai/vantio-pro) | Enforce | Rules that stick | $499/month |
| [**Vantio Phantom Engine**](https://github.com/vantioai/vantio-phantom-engine) | Control — machines you own | Rogue Reconciliation | $799/node |
| **Phantom Engine Enterprise** | Governance on that protection | Ledger, evidence, process | Talk to sales → ~$2k/node |

Start with Optics:

```bash
npm install -g @vantio/cli
vantio run node agent.js
```

Python: `pip install vantio-agent-sdk` and wrap with `shield()` (urllib; requests and httpx when already installed).
