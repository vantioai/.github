# Vantio

**Vantio** is the infrastructure control layer for autonomous AI. Optics observes. Gate enforces where the agent is wired. Phantom Engine is runtime protection on enrolled Linux — enforce and control together, one purchase. Phantom Engine Enterprise adds governance when you need proof and process on top.

Blind by design. Not a proxy. We do not read private conversations.

| Product | Job | Workflow | List |
|---------|-----|----------|------|
| [**Vantio Optics**](https://github.com/vantioai/vantio-open-core) | Observe | Sight Loop | Free |
| [**Vantio Gate**](https://github.com/vantioai/vantio-pro) | Enforce | Rules that stick | $499/month |
| [**Vantio Phantom Engine**](https://github.com/vantioai/vantio-phantom-engine) | Runtime protection on enrolled Linux | Rogue Reconciliation | $799/node |
| **Phantom Engine Enterprise** | Governance on that protection | Ledger, evidence, process | Talk to sales → ~$2k/node |

Start with Optics:

```bash
npm install -g @vantio/cli
vantio run node agent.js
```

Python: `pip install vantio-agent-sdk`, then `vantio run python agent.py` or wrap with `shield()`. Prefixing `vantio run python` does not intercept by itself.
