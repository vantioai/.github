## GitHub issues

Public GitHub issues on `vantio-open-core` and `vantio-optics-cursor-plugin` are for **bugs and concrete product defects** in those public surfaces.

We do **not** promise response times on GitHub issues.

## What GitHub issues are not for

- Sales, pricing, or procurement — use https://vantio.ai or hello@vantio.ai
- Security vulnerabilities — see SECURITY.md
- Phantom Engine private source access

## Contribution posture

Limited external contributions are welcome for Optics open-core (see CONTRIBUTING.md). The Cursor plugin is a small observe-only surface. Private product engines are not open contribution targets.
